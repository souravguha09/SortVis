# SortVis — Sorting Algorithm Visualizer

SortVis is an independent React + Vite project for exploring sorting algorithms through animated bar charts.

## Features

- Bubble, Selection, Insertion, Merge, Quick, and Heap Sort
- Adjustable array size and animation speed
- Start, pause/resume, reset, and regenerate
- Comparisons and swaps highlighted with distinct colors
- Dark and light themes
- Responsive design and complexity summaries

## Getting started

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (typically http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Publish to GitHub

```bash
git init
git add .
git commit -m "Initial SortVis release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/SortVis.git
git push -u origin main
```

Create an empty GitHub repository named `SortVis` first, and replace `YOUR_USERNAME` with your GitHub username.
