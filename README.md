# SortVis – Sorting Algorithm Visualizer

**SortVis** is an interactive, browser-based sorting algorithm visualizer designed to make learning Data Structures and Algorithms (DSA) easier and more engaging. It provides animated visualizations of popular sorting algorithms, helping users understand how elements are compared, swapped, and arranged.

Explore sorting algorithms, experiment with different array sizes, and understand their performance through an interactive interface.

## ✨ Features

- **Interactive Visualizations:** Watch sorting algorithms operate through animated bars.
- **Multiple Algorithms:** Explore popular sorting techniques.
- **Adjustable Array Size:** Generate arrays of different sizes.
- **Speed Control:** Control the speed of sorting animations.
- **Real-Time Animation:** Observe comparisons and element movements.
- **Simple Controls:** Start, pause, reset, and generate new arrays.
- **Responsive Design:** Designed for desktops, laptops, and smaller screens.
- **Algorithm Complexity:** Learn about time and space complexity.

## 🧮 Supported Algorithms

| Algorithm | Average Time Complexity | Worst Time Complexity | Space Complexity |
|---|---|---|---|
| Bubble Sort | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n²) | O(log n) |
| Heap Sort | O(n log n) | O(n log n) | O(1) |

## 🎯 Project Objective

The primary objective of SortVis is to simplify the understanding of sorting algorithms through visual learning. Instead of relying only on theoretical explanations, users can observe how different algorithms process and organize data.

This project is intended for students, programming enthusiasts, and developers who want to strengthen their understanding of sorting algorithms and algorithmic complexity.
